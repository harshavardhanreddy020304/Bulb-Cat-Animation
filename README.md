# 💡 Bulb & Cat Animation

An interactive front-end project that simulates a smart light switch using **HTML5**, **CSS3**, **JavaScript**, and **Bootstrap 4**. Users can toggle the switch to turn the bulb ON or OFF, while the cat reacts with dynamic image changes. This project demonstrates DOM manipulation, event handling, and real-time UI updates in a simple and engaging way.

## 🚀 Features

* Interactive ON/OFF light switch
* Dynamic bulb state changes
* Animated cat image based on switch status
* Real-time status message updates
* Responsive and user-friendly interface
* Smooth interaction using JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 4

## ⚙️ Installation

```bash
git clone https://github.com/your-username/Bulb-Cat-Animation.git
cd Bulb-Cat-Animation
```

Open the `index.html` file in your browser or run the project using the **Live Server** extension in Visual Studio Code.

## ▶️ How to Use

* Open the application in your web browser.
* Click the **ON** or **OFF** switch.
* Watch the bulb change its state instantly.
* Observe the cat image react to the light status.
* Monitor the status text updating in real time.
