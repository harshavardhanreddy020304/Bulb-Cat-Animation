💡 Bulb & Cat Animation
An interactive web project that simulates a light switch using HTML, CSS, JavaScript, and Bootstrap. Toggling the switch turns a bulb ON/OFF and triggers a fun cat animation, demonstrating dynamic UI updates and DOM manipulation.

🚀 Features
-ON/OFF light switch simulation
-Dynamic bulb and cat image changes
-Real-time status text updates
-Clean and responsive UI using Bootstrap

🛠️ Technologies Used
-HTML5
-CSS3
-JavaScript
-Bootstrap 4
